\# PSO Watermarking: влияние состава целевой функции на эффективность



Исследование влияния набора атак, учитываемых в целевой функции, на 

эффективность оптимизации параметров встраивания цифровых водяных знаков 

методом роя частиц (Particle Swarm Optimization, PSO).

\## 📖 О проекте



Цифровые водяные знаки (ЦВЗ) должны оставаться устойчивыми к широкому 

спектру атак — сжатию, шуму, фильтрации, геометрическим преобразованиям. 

При использовании метаэвристической оптимизации (например, PSO) для 

подбора параметров встраивания ключевым становится вопрос:



> \*\*Как выбор набора атак в целевой функции влияет на итоговую 

> робастность и незаметность водяного знака?\*\*



В проекте реализован алгоритм встраивания ЦВЗ с оптимизацией параметров 

методом PSO и проведена серия вычислительных экспериментов:



\- \*\*Официальная абляция\*\* — воспроизведение экспериментов из исходной 

&#x20; статьи, варьирование количества атак в целевой функции.

\- \*\*Исследование специализации\*\* — оценка того, насколько оптимизация 

&#x20; под один набор атак помогает против других (не входивших в целевую 

&#x20; функцию).



\## ✨ Возможности



\- 🐱 \*\*Arnold Cat Map\*\* — перемешивание пикселей водяного знака перед 

&#x20; встраиванием.

\- 🐝 \*\*PSO-оптимизация\*\* параметров встраивания.

\- ⚔️ \*\*Набор состязательных и классических атак\*\* на контейнер 

&#x20; (сжатие, шум, фильтрация и др.).

\- 📊 \*\*Метрики качества\*\*: PSNR, SSIM (незаметность), BER, NC (робастность).

\- 🔬 \*\*Скрипты для воспроизведения экспериментов\*\* с автоматической 

&#x20; выгрузкой результатов в Excel.

📊 Результаты

Итоговые таблицы с метриками незаметности (PSNR, SSIM) и робастности

(BER, NC) при разных составах целевой функции находятся в папке

results/.



Основные выводы исследования:



Увеличение числа атак в целевой функции повышает универсальную

робастность, но может ухудшать незаметность.



Оптимизация под узкий набор атак даёт специализацию: высокую

устойчивость к «своим» атакам и низкую — к остальным.



Существует компромисс между широтой покрытия атак и качеством

изображения-контейнера.
